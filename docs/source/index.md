# ODS Tools

`ods_tools` is the Python toolkit for the Oasis Data Standards: it **loads and
validates** OED exposure, **transforms** other formats to OED (ODTF), converts
currencies, combines ORD results, and generates test data. It also bundles the
`analysis_settings` / `model_settings` schemas.

This site holds executable worked examples; it is pulled into the aggregated Oasis
documentation via intersphinx. The OED/ORD *standards* themselves are single-sourced
in the `ODS_OpenExposureData` / `ODS_OpenResultsData` repositories.
